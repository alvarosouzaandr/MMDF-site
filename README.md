# MMDF Caldeiraria 🏭

Website institucional desenvolvido para a MMDF Caldeiraria, empresa especializada em soluções de caldeiraria industrial, montagens e manutenção para o setor industrial.

O projeto foi criado com foco em presença digital, apresentação dos serviços da empresa, captação de novos clientes e experiência do usuário, garantindo navegação intuitiva e total responsividade em dispositivos móveis e desktops.

## 🚀 Funcionalidades

- Apresentação institucional da empresa
- Catálogo de serviços industriais
- Portfólio de projetos realizados
- Formulário de contato
- Integração com WhatsApp
- Layout responsivo
- Navegação otimizada

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 🎯 Objetivos do Projeto

- Fortalecer a presença digital da empresa
- Facilitar o contato com potenciais clientes
- Apresentar serviços e soluções industriais
- Melhorar a experiência do usuário
